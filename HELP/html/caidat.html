Cài đặt và khởi động

1. Chuẩn bị

Thành phầnYêu cầu
WindowsMáy x64 có quyền cài phần mềm; khuyến nghị RAM 8 GB trở lên
Node.jsTừ 22.12, kèm npm
SQL ServerCài Database Engine; instance mặc định localhost\SQLEXPRESS
ODBCODBC Driver 17 for SQL Server x64 khi dùng Windows Authentication
Công cụ SQLSSMS hoặc sqlcmd để kiểm tra và quản trị
Trình duyệtEdge/Chrome; dùng Edge khi chạy bộ kiểm thử tự động

Cài SSMS không đồng nghĩa đã cài Database Engine. Mở services.msc và kiểm tra SQL Server (SQLEXPRESS) đang Running. Kết nối Windows phải có quyền tạo CSDL khi cài lần đầu.

2. Cài từ mã nguồn

  1. Giải nén hoặc clone repository DBMS_HomeFix. Mở thư mục có CAI_DAT.bat và CHAY_HOMEFIX_DBMS.bat.
  2. Nếu dùng cấu hình mặc định, chạy CAI_DAT.bat và chờ hoàn tất. Script cài thư viện, tạo .env nếu thiếu, sinh khóa JWT, khởi tạo CSDL và build giao diện.
  3. Nếu dùng instance hoặc CSDL riêng, tạo/chỉnh SRC/backend/.env theo .env.example trước bước khởi tạo. Không chia sẻ file chứa khóa và mật khẩu.
  4. Chạy CHAY_HOMEFIX_DBMS.bat. Giữ cửa sổ máy chủ mở trong thời gian dùng.
  5. Mở http://localhost:3000. Kiểm tra đăng nhập và danh mục dịch vụ.

3. Cài thủ công

Chạy terminal tại SRC. Tạo backend/.env theo file mẫu và đặt JWT_SECRET ngẫu nhiên trước khi start.

npm.cmd install
npm.cmd run db:init
npm.cmd run build
npm.cmd start

4. Những lần sử dụng sau

Chạy CHAY_HOMEFIX_DBMS.bat; dừng bằng Ctrl+C. Khi sửa frontend, build lại. Khi nâng cấp CSDL đã có dữ liệu, sao lưu trước khi db:init. Không chạy bộ SQL tạo mới để ghi đè CSDL đang sử dụng.
